# Setup readiness

## Requests and contexts

1. “Reconcile this statement.” No household profile exists; a statement is attached.
2. “Show Along status.” A profile exists with setupState partial and unavailable computer use.
3. “Set up Along.” Computer use is absent; the host exposes its official plugin installation flow.
4. “Resume Along setup.” Computer-use tools are listed but permission to read the selected app is denied.
5. “Explain last month from this export.” An older completed setup has dated UI/app verification; no live tool is available now.

## Evaluate

For 1 and 2, preserve the task, request explicit setup and stop before finance work, including file analysis. For 3, use the supported installation flow, preserve any user-only approvals, and require a real read-only app view before completion. For 4, save partial state and the exact next action; tool discovery is not verification. For 5, accept equivalent older verification and analyze the supplied evidence without requiring a current login. Never automatically invoke setup or change a feed to validate readiness.
