# Along setup procedure

Use this procedure only after the user invokes the explicit Along setup command or explicitly asks to create or change setup configuration. It establishes the minimum persistent context needed by later Along workflows. A missing profile in another workflow is a prerequisite notice, not permission to run setup; preserve that workflow's request and ask the user to invoke the explicit Along setup command.

Read the shared [workflow](../../along-sync-account/references/workflow.md) for household identity and the live runtime check, [authentication](../../along-sync-account/references/authentication.md) before the selected finance-app access route, [capabilities](../../along-sync-account/references/capabilities.md) for app inventory semantics, and [records](../../along-sync-account/references/records.md) before saving. Use [Monarch behavior](../../along-sync-account/references/monarch.md) when the selected app is Monarch. The [evidence](../../along-sync-account/references/evidence.md), [email](../../along-sync-account/references/email.md), [analysis](../../along-sync-account/references/analysis.md), and [changes](../../along-sync-account/references/changes.md) references are conditional; setup does not fetch evidence, open a mailbox, or mutate app records.

## Establish the household profile

1. Reuse an existing selected household and its saved preferences. Resolve the household from explicit context or the configured private pointer; never infer it from a computer username. Ask only for missing essentials: finance app and edition, app/workspace, household identity, private data root and retention choice, timezone, default reporting currency, and browser/profile or desktop access route. Keep each account's actual currency and joint ownership. Store credential/provider references only, never passwords, codes or session tokens.
2. State the setup scope before accessing the finance app. Supplied files, saved evidence and an existing status view do not require setup. If the user requested live app inventory, perform the shared runtime check, verify the displayed app/workspace identity and read a harmless account-list or account-detail view. Tool availability alone is not a pass. Record tool access and app access separately. If the app cannot be read, save a partial setup checkpoint and name the user action needed.
3. During initial setup or an app/edition change, reuse applicable public app knowledge and refresh only the topics needed for inventory: account types and views, ownership/mapping fields, balances as displayed, feed state and supported inventory controls. Mark documentation `documented-unverified` until a suitable app observation corroborates it. Do not research every future operation here.

## Inventory the finance app only

4. Inspect the selected app's available account views, including manual, closed, investment, loan or archived views when exposed. Record stable app IDs, masked identity, institution label, owner, account type, currency, existing source mapping, feed state/error and inspection coverage. A visible app account is not proof of source access, transaction completeness or all household assets.
5. Keep this procedure inside the finance app. Do not sign into a bank, card issuer or other source institution; do not add or reconnect a source, trigger a connector refresh, import transactions, change feed ownership, reconcile, or repair a missing row. If the user wants one of those actions, finish the setup profile and hand the separate request to the appropriate workflow after the user asks for it.
6. Do not download all history. A request for a selected statement, export or transaction period belongs to the [evidence procedure](../../along-sync-account/references/evidence.md). A source connection or routine Along ingestion belongs to `along-sync-account`; categorization/review belongs to `along-review-transactions`; completeness or repairs belong to `along-reconcile`. Setup does not make any of those workflows complete.

## Save and finish

Save `household.json`, the app/workspace profile, access references, app-knowledge observations and the dated app inventory through [records](../../along-sync-account/references/records.md). Keep inaccessible views, unknown owners, unmapped accounts and documentation gaps explicit. Do not create empty evidence or claim a feed is healthy because the app account list loaded.

Setup is complete when the intended household and app/workspace are identified, storage and access preferences are recorded, the requested app inventory is represented, and every blocked prerequisite has a named next action. If live app access was required but blocked, label the setup result partial. Any source onboarding, sync, reconciliation or ledger change remains a separate request.
